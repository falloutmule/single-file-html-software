# Lane routing

- Current new-project lane: `pixi-v8`, initialized from `examples/pixi-minimal`.
- Existing project intake: classify the real primary renderer before changing it. A Canvas2D or ambiguous renderer is an intake/migration decision, not permission to add a hidden Pixi canvas.
- Unimplemented future lanes: remain `DISCUSSION`, `PLAN`, `INTAKE_REQUIRED`, or `BLOCKED` until a current adapter and project contract exist.

Explicit SFHS/Pixi requests route to current SFHS tooling, not Phaser or a substitute framework.
