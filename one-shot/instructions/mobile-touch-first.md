# Mobile touch first

The primary target is physical Samsung Galaxy S21 Ultra Android Chrome. Emulation supports debugging but never proves device acceptance.

Before visual polish, prove the central mobile interaction: independently owned pointer IDs, pointer capture, simultaneous touch operation, cancellation/lost-capture cleanup, blur/visibility cleanup, and safe-area/orientation containment. Record portrait and landscape acceptance criteria separately. A physical report or screenshot that contradicts automation supersedes the old conclusion.
