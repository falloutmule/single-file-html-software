# SFHS WIP Documentation Review Checklist

This checklist applies to the July 2026 public-awareness checkpoint.

## Scope

- [ ] Documentation only.
- [ ] No runtime or build behavior changes.
- [ ] No preview publication changes.
- [ ] No repository archival.
- [ ] No stable plugin API claim.
- [ ] No production-readiness claim.

## Accuracy

- [ ] PixiJS is described as the active lane, not the only lane.
- [ ] Canvas 2D is described as the checked-in baseline.
- [ ] DOM/CSS and raycasting remain visible.
- [ ] Future lanes are marked proposed.
- [ ] Plugin contracts are marked experimental.
- [ ] Automated proof is distinguished from physical acceptance.
- [ ] `sfhs-preview` is described as temporary review hosting.

## Next phase

- [ ] Inspect active source before extracting code.
- [ ] Separate generic SFHS behavior from project-specific behavior.
- [ ] Define only the smallest real plugin seam.
- [ ] Use a minimal fixture before importing a full game.
